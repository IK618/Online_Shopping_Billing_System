Task Cycle 6: Real-Time Inventory Stock Reduction & Manual Quote Quantity Controls
Status: Completed & Verified
Details:
- Resolved stock reduction bug:
  * Catalog SKU cards now compute dynamic `remainingStock = p.stock - (cart[pid] || 0)` in real time.
  * When an item is added to the quote, the visible count immediately counts down (e.g., from 1 -> 0 or 20 -> 19) and shows `(X in quote)`.
  * If available stock reaches 0, the button automatically disables with `Max Stock Reached` (or `Out of Stock`), preventing over-adding.
- Added interactive Quantity Controls to the Digital Quote / Billing Drawer:
  * Stepper `[-]` button: Decrements quote quantity by 1 (removes item cleanly if decremented from 1).
  * Manual Numeric `<input>`: Allows the user to type any desired quantity directly. Automatically clamps to available database stock with an informative alert if exceeded.
  * Stepper `[+]` button: Increments quote quantity by 1 up to maximum database stock. Automatically disables when maximum inventory limit is reached.
- Hardened Backend `/api/checkout`:
  * Enforces strict pre-flight stock validation against SQLite `products.stock`.
  * Rejects overstock requests with HTTP 400 and descriptive error message.
  * Executes relational transaction `UPDATE products SET stock = stock - ? WHERE product_id = ?` on successful order.
  * Refreshes frontend product catalog post-checkout.
- Automated CDP Verification:
  * Confirmed that adding a 1-stock item disables further addition and sets remaining stock to 0.
  * Confirmed stepper `[+]`, `[-]`, and manual input adjust cart quantities and catalog stock in lockstep.

Task Cycle 7: billEX Rebrand, Multi-Tenant Merchant Architecture & RBAC POS Suite
Status: Completed & Verified
Details:
- Rebranded entire application from FastSpring to billEX:
  * Sleek vector brand logo with geometric orange/blue badges and Figtree/JetBrains typography.
  * Active Store identity pill (`Apex Electronics & Retail • Bengaluru • GSTIN: 29ABCDE1234F1Z5`).
  * Role indicator pills distinguishing Store Owner (Admin) vs Cashier Staff.
- Multi-Tenant Schema & Relational Upgrades in SQLite (`store.db`):
  * Added `shops` table with `shop_id`, `shop_name`, `owner_user_id`, `address`, `gstin`, `phone`, `city`, `created_at`.
  * Added `shop_id` foreign key columns to `users`, `products`, and `orders`.
  * Added `billed_by_user_id`, `customer_name`, and `customer_phone` to `orders`.
- Role-Based Access Control (RBAC):
  * Store Owner (Admin): Unrestricted access to Warehouse Inventory creation, Staff Management roster & employee invites, Store Identity/GST profile editing, Dijkstra Route telemetry, NumPy BI analytics, and SQLite database backup dumps.
  * Store Cashier (Employee): Dedicated Fast POS Billing Counter, live SKU search with dynamic stock countdown, quote stepper controls, customer detail inputs, and one-click official invoice printing with cashier attribution. Admin tabs automatically locked with clear security notice and switcher.
- Dynamic Official Tax Invoicing & CSV Export (`billing.py`):
  * Generates ASCII & printable bills headed with the store's physical street address, GSTIN, and contact phone.
  * Includes customer metadata (`CUSTOMER: ... | PHONE: ...`) and cashier attribution (`BILLED BY: Priya Patel (Cashier)`).
  * Automatically zeroes delivery freight if counter sale is within the store's home city (`freight = ₹0.00`).
- Upgraded UI Feedback Engine:
  * Eliminated all legacy browser `window.alert()` calls in favor of accessible, non-blocking floating toast notifications (`role="status" aria-live="polite"`).
  * Fixed string padding calculation in live receipt preview using pure JavaScript `padCenter`.
- End-to-End Visual Chrome DevTools Protocol (CDP) Verification:
  * Verified Owner dashboard, staff management, store profile settings, and inventory tabs.
  * Verified user role switching between Store Owner (`admin_user`) and Cashier (`cashier_priya`).
